# صفحه معرفی ویزیتیک (Landing)

صفحه‌ی ایستای معرفی محصول — کاملاً مستقل از اپلیکیشن (`frontend-app`) و فرانت PHP (`frontend`).
بدون هیچ وابستگی و بدون نیاز به build: فونت وزیرمتن به‌صورت self-hosted استفاده می‌شود.

## ساختار

```
landing/
├── index.html            صفحه اصلی (RTL، فارسی)
├── css/landing.css       استایل‌ها (موبایل‌اول)
├── js/config.js          پیکربندی لینک‌ها — قبل از انتشار تنظیم شود
├── js/landing.js         منوی موبایل و اتصال لینک‌ها
├── fonts/vazirmatn/      فونت وزیرمتن (نسخه self-hosted مشترک با اپ)
└── icons/                آیکون اپ
```

## پیکربندی قبل از انتشار

فایل `js/config.js` را ویرایش کنید:

- `appUrl` — نشانی اپلیکیشن (PWA). مثال: `https://app.vizitik.ir` یا مسیر نسبی.
- `supportUrl` — لینک پشتیبانی (مثلاً ربات یا کانال بله). اگر خالی بماند، لینک «پشتیبانی» از فوتر حذف می‌شود.
- `termsUrl` — صفحه قوانین و مقررات. اگر خالی بماند، حذف می‌شود.

هیچ دکمه یا لینک مرده‌ای باقی نمی‌ماند؛ هر سه مورد به‌صورت داینامیک متصل می‌شوند.

## اجرای محلی

هر سرور ایستایی کافی است، مثلاً:

```bash
cd landing
python3 -m http.server 8080
# یا: npx serve .
```

## استقرار

این پوشه از اپ مستقل است و روی هر هاست ایستایی قابل انتشار است.
گزینه‌ی پیشنهادی روی سرور فعلی (nginx): انتشار پوشه به‌صورت root دامنه یا مسیری
مثل `/welcome/`، بدون دست‌زدن به پیکربندی فعلی nginx که PWA را سرو می‌کند.
