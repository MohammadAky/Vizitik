## 🌟 معرفی پروژه

**ویزیتیک (Vizitik)** یک راهکار صنعتی و کامل برای شرکت‌های پخش مویرگی مواد غذایی و بستنی (نظیر میهن و پاندا) است که به ویزیتورها و رانندگان پخش گرم امکان می‌دهد:
- موجودی بار داخل خودرو (Van Inventory) را بارگیری و مدیریت کنند.
- سفارشات مشتریان را بر مبنای تفکیک دقیق **کارتن و دانه** ثبت نمایند.
- تخفیفات ترکیبی (درصدی و نقدی) را به صورت **پلکانی و لحظه‌ای** اعمال کنند.
- مبالغ فاکتور را به تفکیک **نقد، کارتخوان، چک صیادی و نسیه دفتری** تسویه نمایند.
- فاکتور حرارتی استاندارد **۸۰ میلی‌متری** را چاپ کرده و جزئیات را به ربات بله ارسال نمایند.
- در صورت تغییر نحوه پرداخت توسط مشتری پس از چند روز، روش‌های تسویه فاکتور را ویرایش و مانده دفتر حساب را همگام سازند.

## 🏗 معماری و پشته فناوری

### بک‌اند (Backend)
- **فریم‌ورک:** [NestJS](https://nestjs.com/) (TypeScript) بر پایه معماری ماژولار و تزریق وابستگی (DI)
- **ORM و دیتابیس:** [Prisma ORM](https://www.prisma.io/) متصل به **MySQL / MariaDB** (پشتیبانی کامل از تراکنش‌های مالی ACID)
- **احراز هویت:** JWT (JSON Web Token) + پاسپورت با استراتژی احراز هویت بدون OTP در ورود روزمره و OTP اختصاصی در ثبت‌نام و بازیابی رمز
- **ربات و اعلان‌ها:** Bale Bot API (سازگار با Telegram HTTP REST API) جهت ارسال آنی فاکتور و کدهای اعتبارسنجی

### فرانت‌اند (Frontend)
- **زبان و رندرینگ:** PHP 8+ با معماری Responsive Mobile-First و بهینه‌سازی شده برای گوشی‌های لمسی و تبلت‌ها
- **طراحی رابط کاربری:** CSS3 ماژولار با طراحی تیره برند (`#001d31`)، فونت زیبای **وزیرمتن (Vazirmatn)** و آیکون‌های گوگل متریال
- **جاوااسکریپت:** Pure Vanilla JavaScript (بدون وابستگی سنگین) با محاسبات بدون خطا و سیستم نوتیفیکیشن درون‌فریم

## 🚀 قابلیت‌های کلیدی سیستم

### ۱. بارگیری خودرو و قفل موجودی (Van Loading)
- نمایش کاتالوگ محصولات شرکتی (میهن، پاندا و کالاهای دست‌ساز ویزیتور)
- بارگیری بر اساس تعداد کارتن و دانه خرده با محاسبه ارزش ریالی کل بار
- معماری بدون افزونگی داده (Lean Architecture): عدم ثبت رکوردهای صفر در دیتابیس

### ۲. ثبت سفارش فروش گرم (Hot Selling Order)
- فیلتر سخت‌گیرانه: صرفاً نمایش کالاهایی که در خودرو بارگیری شده و موجودی مثبت دارند.
- اولویت انتخاب: کارتن ابتدا، سپس دانه خرده.
- محدودیت دانه در کارتن: جلوگیری از انتخاب دانه مساوی یا بیشتر از ظرفیت کارتن (`unitCount < unitsPerCarton`).
- کنترل سقف موجودی فیزیکی کل خودرو.

### ۳. موتور تخفیفات پلکانی (Stepped Discount Engine)
- قرارگیری بخش تخفیف بالای روش‌های پرداخت برای مشاهده قیمت خالص قبل از تسویه.
- امکان ثبت چندین تخفیف درصدی و نقدی متوالی (پله ۱، پله ۲ و ...).
- کسر پلکانی تخفیف‌ها از مانده ناخالص و نمایش تفکیکی هر پله به همراه دکمه حذف اختصاصی.

### ۴. تسهیم و تسویه ۴ گانه فاکتور (Payment Split)
- پشتیبانی همزمان از **نقدی**، **کارتخوان / پوز**، **چک صیادی** و **نسیه (مانده دفتری)**.
- ثبت مشخصات کامل چک صیادی (شناسه ۱۶ رقمی، نام بانک و انتخاب‌گر تقویم شمسی).
- ثبت خودکار مانده تسویه‌نشده در دفتر حساب مشتری (`customer_ledger`).

### ۵. مدیریت، ویرایش و چاپ مجدد فاکتورها (`orders.php`)
- مشاهده تاریخچه تمام فاکتورهای صادر شده همراه با وضعیت تسویه.
- امکان **ویرایش و اصلاح روش‌های پرداخت فاکتور** در روزهای بعد و همگام‌سازی مانده بدهی مشتری.
- چاپ فاکتور حرارتی ۸۰ میلی‌متری با تمام جزئیات فی دانه، فی کارتن، چک و مانده حساب.

### ۶. وصول مطالبات و دفتر حساب (`collections.php`)
- نمایش مجموع طلب بازار و تفکیک فروشگاه‌های بدهکار.
- فرم دریافت وجه (نقد، پوز، چک) و کسر آنی از مانده بدهی مشتری در دیتابیس.
- خروج خودکار مشتری از لیست بدهکاران پس از تسویه کامل.

## 📐 قوانین تجاری و محاسباتی (FMCG)

1. **فرمول قیمت‌گذاری کترینگ بستنی:**
   $$\text{Carton Price} = \text{Unit Price} \times \text{Units Per Carton}$$
2. **محاسبه تخفیف پلکانی:**
   $$A_0 = \text{Subtotal}$$
   $$D_i = \frac{A_{i-1} \times P_i}{100} \quad \text{یا} \quad D_i = \min(A_{i-1}, F_i)$$
   $$A_i = A_{i-1} - D_i$$
3. **محاسبه مانده نسیه دفتری:**
   $$\text{Credit (نسیه)} = \max(0, \text{Final Amount} - (\text{Cash} + \text{POS} + \text{Check}))$$

## 🛠 راهنمای راه‌اندازی سریع

### ۱. پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- PHP نسخه 8.0 یا بالاتر به همراه اکستنشن‌های `curl` و `json`
- دیتابیس MySQL / MariaDB

---

### ۲. راه‌اندازی بک‌اند (NestJS + Prisma + MySQL)

```bash
# ۱. ورود به دایرکتوری بک‌اند
cd backend

# ۲. نصب پکیج‌ها
npm install

# ۳. تنظیم فایل متغیرهای محیطی (.env)
cp .env.example .env
# مقادیر DATABASE_URL، JWT_SECRET و BALE_BOT_TOKEN را در .env تنظیم کنید

# ۴. اجرای مایگریشن‌های پریزما و ساخت جداول
npx prisma db push

# ۵. بارگذاری داده‌های اولیه (کاربر پیش‌فرض، کاتالوگ کالاها و مشتریان)
npx prisma db seed

# ۶. اجرای سرور بک‌اند در حالت توسعه
npm run start:dev
# سرور بر روی پورت 3000 اجرا می‌شود: http://localhost:3000
```

#### نمونه فایل `.env` بک‌اند:
```env
PORT=3000
DATABASE_URL="mysql://root:password@localhost:3306/vizitik_db"
JWT_SECRET="vizitik_super_secure_jwt_secret_key_2026"
JWT_EXPIRES_IN="30d"
BALE_BOT_TOKEN="2089208057:mqfJ2g1Vbxn-gdtP7e3Lm6T24ou6WK0CuFc"
BALE_ADMIN_CHAT_ID="542633638"
```

---

### ۳. راه‌اندازی فرانت‌اند (PHP + Responsive Web/PWA)

```bash
# ۱. ورود به دایرکتوری فرانت‌اند
cd frontend

# ۲. اجرای سرور داخلی PHP یا قرار دادن روی وب‌سرور (Apache / Nginx / XAMPP)
php -S localhost:8000

# ۳. باز کردن برنامه در مرورگر
# http://localhost:8000
```

> **اطلاعات ورود پیش‌فرض:**
> - **شماره موبایل:** `09121234567`
> - **رمز عبور:** `123456`

## 🤖 یکپارچه‌سازی با ربات بله (Bale Messenger Bot)

این سامانه مستقیماً به API پیام‌رسان بله متصل است و عملیات زیر را به صورت خودکار انجام می‌دهد:
- **ارسال پیام اعلان راه‌اندازی سرور** به چت پیش‌فرض سوپروایزر (`542633638`).
- **ارسال پیام فاکتور صادر شده** شامل نام مشتری، جمع ناخالص، مجموع تخفیفات، مبلغ نهایی و روش‌های تسویه.
- **ارسال کدهای OTP** جهت ثبت‌نام ویزیتور جدید و بازیابی رمز عبور.
