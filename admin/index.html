      آمار جدول‌ها

      ساختار جدول:
      هنوز کوئری‌ای اجرا نشده است

      کوئری را بنویسید و «اجرای کوئری» را بزنید. از Ctrl+Enter هم می‌توانید استفاده کنید.

      🔎 روی هر قالب کلیک کنید تا در ویرایشگر بارگذاری شود، سپس «اجرای کوئری» را بزنید. (نام جدول‌ها همان نام واقعی دیتابیس است: products، orders، customers و ...)

      📦 همه محصولات

      لیست کامل محصولات با قیمت‌ها

      SELECT * FROM products ORDER BY brand, name

      📊 محصولات پرفروش

      محصولات به ترتیب تعداد سفارش

      SELECT p.name, p.brand, COUNT(oi.id) AS orderCount FROM products p LEFT JOIN order_items oi ON p.id = oi.productId GROUP BY p.id, p.name, p.brand ORDER BY orderCount DESC

      📋 سفارشات اخیر

      ۱۰۰ سفارش آخر با نام مشتری و ویزیتور

      SELECT o.invoiceNumber, o.orderDate, o.status, o.finalAmount, c.name AS customerName, CONCAT(u.firstName, ' ', u.lastName) AS visitorName FROM orders o JOIN customers c ON o.customerId = c.id JOIN users u ON o.visitorId = u.id ORDER BY o.orderDate DESC LIMIT 100

      ⏳ سفارشات در انتظار

      سفارشات پیش‌نویس (تایید نشده)

      SELECT * FROM orders WHERE status = 'DRAFT' ORDER BY orderDate DESC

      💰 بدهکاران

      مشتریانی که مانده حسابشان مثبت است (بدهکار)

      SELECT c.name, c.phone, cl.balanceAfter AS debt FROM customers c JOIN customer_ledger cl ON cl.customerId = c.id WHERE cl.balanceAfter > 0 AND cl.id = (SELECT cl2.id FROM customer_ledger cl2 WHERE cl2.customerId = c.id ORDER BY cl2.createdAt DESC LIMIT 1) ORDER BY debt DESC

      💳 خلاصه پرداخت‌ها

      تعداد و مجموع پرداخت‌ها به تفکیک روش

      SELECT method, COUNT(*) AS paymentCount, SUM(amount) AS total FROM payments GROUP BY method ORDER BY total DESC

      🏃 عملکرد ویزیتورها

      تعداد سفارش و فروش هر ویزیتور

      SELECT CONCAT(u.firstName, ' ', u.lastName) AS visitorName, COUNT(o.id) AS orderCount, COALESCE(SUM(o.finalAmount), 0) AS totalSales FROM users u LEFT JOIN orders o ON o.visitorId = u.id WHERE u.role = 'VISITOR' GROUP BY u.id, u.firstName, u.lastName ORDER BY totalSales DESC

      🚚 موجودی ون

      موجودی فعلی ون ویزیتورها

      SELECT u.firstName, u.lastName, p.name AS productName, vi.quantityCartons, vi.quantityUnits FROM van_inventory vi JOIN users u ON vi.userId = u.id JOIN products p ON vi.productId = p.id ORDER BY u.firstName, p.name

      📈 درآمد ماهانه

      درآمد به تفکیک ماه میلادی (سفارش‌های لغوشده حساب نمی‌شوند)

      SELECT DATE_FORMAT(orderDate, '%Y-%m') AS month, COUNT(*) AS orderCount, SUM(finalAmount) AS revenue FROM orders WHERE status <> 'CANCELLED' GROUP BY month ORDER BY month DESC

      📊 آمار دیتابیس

      تعداد ردیف هر جدول

      SELECT TABLE_NAME AS tableName, TABLE_ROWS AS rowCount FROM information_schema.TABLES WHERE TABLE_SCHEMA = DATABASE() ORDER BY TABLE_ROWS DESC

      🔍 تنظیمات SQL

      🔒 هر کوئری SELECT در ویرایشگر حداکثر ۵۰۰ ردیف برمی‌گرداند (محدودیت سمت سرور). برای گرفتن کل داده‌ها از دکمه «خروجی کامل» استفاده کنید که تا ۲۰٬۰۰۰ ردیف می‌گیرد.

      برای INSERT/UPDATE/DELETE پیام تایید نمایش داده شود
